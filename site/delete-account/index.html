계정 삭제

초안 — 법률 검토가 필요합니다

앱에서 삭제하기

  1. 설정 화면 아래쪽 "공간" 묶음에서 "계정 삭제"를 선택합니다.
  2. 안내를 읽고 확인한 뒤 같은 로그인 방식으로 다시 로그인합니다.
  3. 마지막 삭제 버튼을 누릅니다. 인터넷 연결이 필요합니다.

삭제하면

요청이 접수되면 모든 기기에서 로그아웃되고 로그인 식별자(인증 계정), 프로필 정보, AI 처리 동의 기록, 대기 중인 초대 코드가 바로 삭제됩니다. 동의 기록의 최종 보관 여부는 법률 검토 중입니다. Apple로 로그인했다면 앱과의 연결(토큰)도 해제합니다. 유예나 이용자 직접 복구는 없고, 데이터 내보내기도 제공하지 않습니다.

함께 쓰던 공간은 종료되어 두 사람 모두 즉시 접근할 수 없고, 계정 삭제의 경우 보관 기간 없이 바로 완전히 삭제됩니다. 방, 홈 커버 사진, 생성 장식, 프롬프트 기록, 관련 신고와 생성 시도 기록이 포함됩니다. 상대에게는 이름 없이 "상대가 계정을 삭제했어요"라는 안내가 한 번 보입니다. 개인정보가 없는 기록(공간 종료·삭제 시각, 신고의 종류·사유·시각만 담은 지문, 생성 차단 지문)은 남으며 보관 기간은 법률 검토 중입니다.
