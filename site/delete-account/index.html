계정 삭제

초안 — 법률 검토가 필요합니다

앱에서 삭제하기

  1. 설정 화면 아래쪽 "계정" 묶음에서 "계정 삭제"를 선택합니다.
  2. 안내를 읽고 "내용을 확인했어요"를 켭니다.
  3. "Apple로 다시 로그인해 확인"을 눌러 본인을 확인하면 삭제가 진행됩니다. 인터넷 연결이 필요합니다.

삭제하면

요청이 접수되면 모든 기기에서 로그아웃되고 로그인 정보(인증 계정), 프로필 정보(이름, 생일), 대기 중인 초대 코드가 바로 삭제됩니다. Apple 연결도 해제합니다. 유예나 이용자 직접 복구는 없고, 데이터 내보내기도 제공하지 않습니다.

함께 쓰던 공간은 종료되어 두 사람 모두 즉시 들어갈 수 없고, 사귄 날과 직접 추가한 기념일을 포함한 공간 데이터가 보관 기간 없이 바로 완전히 삭제됩니다. 상대에게는 이름 없이 "상대가 계정을 삭제했어요"라는 안내가 한 번 보입니다. 공간 종료·삭제 시각처럼 개인정보가 없는 운영 기록은 남을 수 있습니다.
