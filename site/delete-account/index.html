계정 삭제

초안 — 법률 검토가 필요합니다

앱에서 삭제하기

  1. 설정 → 위험 구역 → 계정 삭제를 선택합니다.
  2. 안내를 읽고 확인한 뒤 같은 로그인 방식으로 다시 로그인합니다.
  3. 마지막 삭제 버튼을 누릅니다. 인터넷 연결이 필요합니다.

삭제하면

요청이 접수되면 모든 기기에서 로그아웃되고 로그인 식별자, 프로필 개인 정보와 AI 처리 동의 기록은 즉시 삭제되거나 익명화됩니다. 동의 기록의 최종 보관 여부는 법률 검토 중입니다. 활성 공간은 종료되어 두 사람 모두 즉시 접근할 수 없습니다. 유예나 이용자 직접 복구는 없습니다.

종료된 공간의 데이터는 서버 내부에 보관된 뒤 30일 후 완전히 삭제됩니다. 홈 커버 사진, 생성 장식, 프롬프트 기록, 관련 신고 및 생성 시도 기록도 포함됩니다. 개인정보가 없는 생성 차단 지문은 남습니다. 공간이 참조하는 동안 개인 필드가 비워진 프로필 껍데기가 남고, 참조가 사라지면 삭제됩니다.
