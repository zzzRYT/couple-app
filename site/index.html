자주 묻는 질문

아룸은 어떤 앱인가요?

두 사람이 연결해 사귄 날과 기념일을 함께 기록하고 날짜를 확인하는 앱입니다.

두 사람은 어떻게 연결하나요?

한 사람이 앱에서 새로 시작하기를 선택해 사귄 날을 입력하고 초대 코드를 만들면, 상대가 초대 코드 입력 화면에서 코드를 입력합니다. 코드는 24시간 안에 한 번 사용할 수 있습니다.

초대 코드는 얼마나 사용할 수 있나요?

초대 코드는 생성 후 24시간 안에 한 번 사용할 수 있습니다.

기념일 알림은 어떻게 설정하나요?

앱 설정의 알림에서 기념일 알림을 켤 수 있으며, 기기의 알림 설정에서도 아룸 알림을 허용해야 합니다.

계정을 삭제하려면 어떻게 하나요?

앱 설정의 계정에서 계정 삭제를 선택해 본인 확인을 진행하세요. 자세한 내용은 계정 삭제 안내를 확인해 주세요.
