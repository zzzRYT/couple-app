초안 — 법률 검토가 필요합니다

이 문서는 아룸 앱이 지금 실제로 다루는 정보를 설명합니다.

처리하는 정보

  • 로그인 정보: Apple 로그인으로 받은 계정 식별자와 이메일 주소. Apple의 "나의 이메일 가리기" 주소일 수 있습니다. Apple에서 이름은 받지 않습니다.
  • 프로필: 직접 입력한 이름, 선택해서 입력한 생일(월·일)과 태어난 해. 태어난 해는 본인만 볼 수 있습니다.
  • 공유 공간: 사귄 날, 공간 시간대, 직접 추가한 기념일(제목, 날짜, 반복, 메모), 두 사람의 연결 정보.
  • 초대 코드: 코드 원문이 아니라 해시 값을 저장합니다. 코드 입력 시도 횟수도 추측을 막기 위해 기록합니다.
  • 접속 기록: 서비스 제공자의 서버에 접속 IP 등 요청 기록이 남을 수 있습니다.

광고와 분석 도구를 쓰지 않고, 이용자를 추적하지 않습니다. 위치, 연락처, 사진은 수집하지 않으며 AI 서비스로 보내는 정보도 없습니다.

이용 목적

로그인과 계정 유지, 두 사람의 연결, 두 기기에 같은 날짜와 기념일을 보여 주는 일, 초대 코드 남용 방지에만 씁니다.

함께 보는 사람

연결된 상대는 내 이름, 내가 넣은 생일(월·일), 사귄 날, 직접 추가한 기념일을 봅니다. 그 밖의 다른 이용자에게는 공개되지 않습니다.

이 기기에만 저장되는 정보

기념일 알림은 기기 안에서 예약되고 서버로 보내지 않습니다. 언어와 화면 모드, 위젯에 표시할 데이터, 마지막으로 받은 공간 데이터의 사본도 기기에 저장됩니다. 로그아웃, 연결 끊기, 상대의 연결 끊기나 계정 삭제, 내 계정 삭제 때 공간 관련 데이터와 예약 알림이 기기에서 지워집니다.

처리를 맡기는 곳

  • Supabase: 데이터베이스, 로그인, 실시간 동기화.
  • Apple: Apple 로그인과 계정 삭제 시 연결 해제.
  • Expo: 앱 업데이트 전달. 운영체제, 프로젝트 ID, 설치별 임의 토큰이 전송됩니다.
  • Cloudflare: 이 웹사이트 호스팅.

이 업체들은 위 서비스를 제공하는 데 필요한 범위에서만 정보를 처리하며, 이 방침에서 설명한 것과 같은 수준으로 정보를 보호해야 합니다.

보관과 삭제

  • 연결 끊기: 두 사람 모두 즉시 공간에 들어갈 수 없고, 공간 데이터는 서버에서 30일 뒤 완전히 삭제됩니다. 이용자가 직접 복구할 수 없습니다.
  • 계정 삭제: 로그인 정보와 프로필이 삭제되고, 속해 있던 공간은 30일을 기다리지 않고 바로 완전히 삭제됩니다. Apple 연결도 해제합니다.
  • 남을 수 있는 기록: 공간 종료·삭제 시각처럼 개인정보가 없는 운영 기록.
