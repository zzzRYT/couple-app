# Implementation notes

- T002: Expo SDK 58 recommends Skia 2.14.0; 3.7.4 is not available in the package registry. The SDK-compatible version is used until the compatibility matrix is revisited.
- The machine's pnpm shim has no configured version; use `corepack pnpm`, pinned by `packageManager` in the root package.
- T012 mentions four schemas, but the contracts directory contains five and T009 requires byte identity for all `*.schema.json` files. The sync copies all five, including the later-phase generated-object contract.
- The original scene schema required a mascot in every scene, conflicting with FR-018c and T064's removal and recall flow. The contract now permits zero or one in existing scenes; initial scenes separately require exactly one. §11 gives no numeric initial placement, so a centered lower-room placeholder is used pending layout verification.
- T023 requires nonempty translations, but the design copy left three English date-wheel labels empty. The source now uses draft Year/Month/Day labels, subject to the planned native-language review (G4).
- T022 precedes the room-theme table (T067), yet needs the room timezone. The space holds the timezone from creation; room initialization and later room-mode changes must keep it synchronized. Quota RPCs are restricted to the service role so clients cannot finalize failures themselves or increase the limit.
- T028/T029: the source CSV has inconsistent trailing columns on some placeholder rows, so the importer tolerates extra columns while selecting IDs and variants. There are 24 catalog entries and 25 image files because the lamp has a night variant.
- T027 conflicts with handoff's removal of Inter; the task explicitly asks for Inter, so it is retained. The nine static Google Fonts files total about 40 MB uncompressed, larger than the design estimate; EAS artifact measurement and font selection remain G6.
- T034 references a loader `WINDOW_SVG` in `design/boards S03`, but that file or symbol is absent in this checkout. A small loader-only window sketch using the design palette is supplied and kept out of the catalog.

## Phases 3-5 (server, 2026-10-27)

App-side notes are in `docs/implementation-notes-app.md`.

- **Edge Function routing**: the app calls `/functions/v1/{function}{logical path}`; each function matches the logical route of `contracts/api.md` by suffix. Functions: `spaces`, `invitations`, `profile`, `prompt-session`, `ai-consent`, `decoration-previews`, `room`, `lifecycle-sweep`, `home-cover`. Business rules live in `security definer` SQL RPCs that take the verified caller as `actor` and are executable only by `service_role`; the functions verify the JWT, enforce `Idempotency-Key` and map stable error codes to statuses.
- **Contract additions** (recorded in `contracts/api.md`): `POST /spaces` also takes `timeZone` (the creator's IANA zone, the room zone's initial value); invitation failure codes `INVITE_INVALID`, `INVITE_EXPIRED`, `INVITE_USED`, `SPACE_FULL` follow the names already in `design/i18n-copy.md`; `POST /invitations/preview` serves the `join.found.*` confirm step without consuming the code (no display names exist, so no partner name is returned); common codes `INVALID_REQUEST`, `UNAUTHORIZED`, `NOT_FOUND`, `CONSENT_REQUIRED`, `SESSION_EXPIRED`.
- **T036 / T096**: `GET /spaces/mine` needs the end notices that US5 creates, so a minimal `space_end_notice` table and `POST /spaces/mine/ended/ack` are added now; US5 only has to write notices when spaces end.
- **T040 invitation reissue**: there is no unique index on active codes per space; reissue revokes the previous code under the space row lock.
- **T042 attempt limit**: failed code checks are recorded only for invalid, expired or used codes (not `ALREADY_IN_SPACE` or `SPACE_FULL`). Limit 10 per hour per user, both server settings in `app_settings`.
- **T046**: local sign-in emails use `supabase/templates/otp.html`, which carries the 6-digit code and the link (placeholder copy until G1/G4).
- **T054 concurrency**: the pgTAP test proves the single-occupant rule with the partial unique index and sequential calls; true parallel acquires are covered by the Deno test that fires two requests at once.
- **T057 lease expiry** is lazy: every session call marks expired leases under the space row lock, so no scheduler is needed for expiry.
- **T059**: Realtime authorization is an RLS policy on `realtime.messages` for private `space:<id>` channels; only server functions publish (`realtime.send`), and payloads carry ids, states, version numbers and times only.
- **T067 / T068**: the initial-room change is its own migration (`20261101000650_init_room.sql`). pgTAP cannot run the Ajv validator, so the "initial scene passes the shared validator" check is a Deno test (`room/__tests__/initial_room.test.ts`); pgTAP checks the structure. The catalog seed lives in `supabase/seed/catalog.sql` (generated by `tools/catalog/build-seed.mjs`); the owner must load it on the remote project once (`psql … -f supabase/seed/catalog.sql`) because `db push` does not run seeds.
- **Initial room values**: §11 gives no numeric placement, so the D-day widget defaults to a centered top card (`x 0.5, y 0.17, 0.84 × 0.14`); presentation coordinates are normalized centers like scene nodes.
- **T071 model call**: the official SDK (`npm:@anthropic-ai/sdk`) with structured output (`output_config.format` JSON schema) on `claude-haiku-5-5` at low effort; `AI_ESCALATE_TO_SONNET=true` lets the single repair attempt use `claude-sonnet-5-5`. A missing key, provider error, refusal or non-final stop reason fails closed as `503 GENERATION_FAILED` without spending the daily quota. The model never changes room mode or time zone; those stay a shared setting.
- **T072 order**: membership, active space, both consents, lease owner, base version and prompt length are checked, then the quota slot is reserved, in one transaction before any model call. A deterministic mascot-change filter (ko/en/ja) rejects with `422 UNSUPPORTED_REQUEST` before the model. Every failure path releases the reservation; requests stranded by a crash are released by `lifecycle-sweep` after 10 minutes.
- **Lock order**: functions that touch the quota take the space row lock before the quota advisory lock; the reverse order deadlocked under parallel previews.
- **Preview validity** is 30 minutes (`preview_ttl_seconds`), an assumption; the lease still has to be held to apply.
- **Edge runtime imports**: the runtime has no sloppy imports, so `packages/scene-contract` now uses explicit `.ts` import paths (`allowImportingTsExtensions` in `tsconfig.base.json`), and `supabase/functions/deno.json` maps Ajv for every function (`config.toml`). `lifecycle-sweep` checks the service-role key itself (`verify_jwt = false`).
- **Lint gate (T008)**: see the app notes; `no-restricted-syntax` selectors now enforce FR-019.
- **Rename**: the steer renaming Mopiru/Mopi to Aroom/Aroomi is applied to code identifiers (identity placeholders, workspace name). After the design-source rename (PR #5) merged, the i18n resources, tokens, scene-contract schemas and catalog were regenerated from the renamed sources.

## Phase 7 (US5, 2026-10-29)

- **Migration name**: `20261101000700` was already taken by `lifecycle_sweep`, so T095 lives in `20261101000750_lifecycle_report.sql`.
- **One soft delete, three reasons**: `end_space(actor, space, reason)` serves end, disconnect (`block` endpoint) and the future account deletion (`account_deletion`: only the partner gets a notice, `account_deleted`). It runs in one transaction under the space row lock: status, `purge_after` (= now + `purge_after_days`, default 30, in `app_settings`, never returned), both members inactive, open lease released (`space_ended`), open invitations revoked, notices, lifecycle event, then a content-free `member`/`ended` broadcast so the partner's app refreshes at once. A second caller (the partner after the first ended it) gets `404`.
- **Non-members get 404, not 403** (T091 said 403): the whole API already hides membership behind `404`; the contract notes this.
- **Purge is split**: Storage cannot be called from SQL, so `lifecycle-sweep` runs `due_purge_spaces` → `mark_purge_started` → Storage removal (private bucket `home-cover`, prefix `<spaceId>/`, missing bucket = nothing to delete; the bucket is created by `20261102000500_home_cover.sql`) → `purge_space` (one transaction). `purge_space` sets `app.purging` locally because room versions are immutable otherwise. `space_lifecycle_event.space_id` lost its foreign key so `deletion_started`/`deletion_completed` outlive the space; `purge_space` blanks the actor and metadata of the older events. The sweep is **not scheduled**.
- **Reports**: `report` table plus `submit_report`; `generated_object`/`copyright` and `GET …/reports/mine` stay with US9. Contact email stays the `[지원 이메일]` placeholder from the design copy (G10).
- **App**: `/settings/end-space`, `/settings/report` and `/ended` sit outside the tab group so the tab bar is hidden. `EndedGate` (root layout) sends the person through the entry screen once when an open space stops being active; `app/index.tsx` shows `/ended` first while an unread notice exists. `leaveSpace` releases a lease the person holds, ends/disconnects, clears the cached space state and reloads the entry state; a `404` counts as "already ended". Partner names are the generic "상대" (no display names exist).
- **Message report**: `PromptPanel` takes an optional `onReportMessage`; partner messages get a "⋯" button that opens the report sheet, then `/settings/report?messageId=…`.
- **Tests**: pgTAP `lifecycle.test.sql`, `purge.test.sql`; Deno `spaces/__tests__/end.test.ts`, `block.test.ts`, `reports/__tests__/reports.test.ts`, `lifecycle-sweep/__tests__/purge.test.ts` (fixed clock `2001-01-01` so spaces from other runs are never purged); Jest `features/lifecycle/__tests__`.
