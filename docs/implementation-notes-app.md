# App implementation notes (apps/mobile, Phases 2-5)

- **Partner names**: the data model stores no display names, but several keys interpolate `{name}` (`prompt.partner`, `prompt.takeover.*`, `room.partnerLive`, `join.found.title`, `join.ok.body`, `main.chip.both`). Screens pass the generic `report.target.partner` value ("상대" / "My partner") as `{name}`; the join confirm step shows only `join.found.heading` and `join.found.body` (with the date), and the join success step shows only `join.ok.title`. `main.chip.both` is not shown.
- **D-day accessibility sentence**: `a11y.dday` carries a fixed sample date, so the widget and home label are composed from `dday.eyebrow` + `dday.count` + the `Intl`-formatted anniversary. The same applies to `date.since` (sample text); the home screen shows the `Intl` date alone.
- **Copy button and paste**: no clipboard module is installed (adding one would change the root lockfile). The invite screen offers the OS share sheet only; the join screen relies on the text field's native paste and shows a paste button only when a `readClipboard` function is supplied. Adding `expo-clipboard` would enable both.
- **OAuth**: Kakao/Apple run through `signInWithOAuth` + `Linking` redirect (`auth-callback`) behind placeholder buttons (`login.brandNote`) until the official SDKs (G5). There is no `expo-web-browser`, so a cancelled browser flow is resolved by the screen's cancel button.
- **Day/night**: `follow_time` uses 06:00-18:00 in the room time zone as day (assumption; the spec leaves the switch hours open). One place: `src/scene/dayNight.ts`.
- **Protected zones on the client**: decorations that intrude are not drawn (the server already validates); an intruding mascot falls back to its default placement. The layout uses the design defaults (iOS 47/34, Android 32/24, 56pt toolbar scaled up to 160% text, 49/56pt tab bar) and adds the D-day widget frame.
- **Withdrawn consent**: there is no dedicated "preview discarded" key, so withdrawing with an unapplied preview shows `consent.withdraw.done` plus `preview.cancel.toast`.
- **Offline**: the last snapshot is kept in memory only (not persisted); while offline the snapshot is retried every 15 seconds and on foreground. Nothing is queued.
- **Mascot auto recall**: once per room opening when the mascot is missing, nobody holds a live lease and the app is online (`src/features/room/recallPolicy.ts`).
- **Image requires**: Metro does not resolve explicit `@2x.png` requests, so app code requires `name.png` and Metro picks the `@2x` file. `src/scene/catalogImages.ts` uses the same paths, and `tools/catalog/build-manifest.mjs` now emits them. Jest maps the suffix-free paths back with `moduleNameMapper`.
- **Skia in Jest**: `@shopify/react-native-skia` is mapped to `src/test/skiaMock.tsx` (View stand-ins), so render tests check what would be drawn, not pixels.
- **Lint gate (T008)**: `i18next/no-literal-string` 6.1.5 reports nothing under the flat config (verified with a probe file), so `eslint.config.mjs` also enforces FR-019 with `no-restricted-syntax` selectors on JSX text, literal JSX children and display props in `features/**` and `ui/**` (tests excluded).
- **Rename**: identity placeholders now use Aroom / `com.jinjinstar.aroom` / `aroom.jinjinstar.com`. `src/theme/tokens.ts` (generated from `design/tokens.json`) and the locale JSON still contain the old names and are left to their generators.
