# contrast-report.md — WCAG 2.2 대비 보고서 (방향 A)

측정: `lib/contrast`와 같은 계산(상대 휘도 L = 0.2126R + 0.7152G + 0.0722B, sRGB 선형화 후 (L1+0.05)/(L2+0.05))을 모든 쌍에 적용했어요. 기준은 일반 글자 4.5:1, 큰 글자·비문자(컨트롤 경계·아이콘·포커스) 3:1이에요. 조합은 방(낮|밤) × 앱(밝게|어둡게) × (보통|고대비) 8가지이고, 쌍은 58종 × 8 = **464개**, 기준 미달 **0개**예요(참고 행은 기준에서 제외).

## 고친 것 (이력)

1. **어두운 방에서 갈색 윤곽선이 묻히는 문제**(1단계 A의 숙제): 윤곽선 #4A3426은 밤 벽 #2B2320에서 1.33:1이에요. 고정 이미지라 윤곽선 색을 바꿀 수 없어서 윤곽선 바깥에 **크림 림 #FFF4DF**를 한 겹 두르기로 했어요(밤 벽 14.12:1, 밤 바닥 12.76:1). 낮 방에서는 윤곽선이 벽 10.38:1, 바닥 8.99:1로 읽혀요.
2. **방 도구 막대 경계가 앱 모드에 흔들리는 문제**: 윤곽선을 앱 모드(밝게=갈색, 어둡게=크림)에 맞췄더니 어두운 앱 + 낮 방에서 복숭아색 주 버튼의 경계가 크림 벽 위에서 1.55~1.80:1로 실패했어요(2건). 윤곽선을 방에 맞추도록 바꿨어요(낮 방=갈색, 밤 방=크림, 고대비는 더 진하게). 1단계 B에서 지적된 "밝은 방 위의 흰 컨트롤" 문제도 같은 방식(윤곽선)으로 해결돼요.
3. **시스템 탭 바**: 막대 재질·배경은 OS 소유예요. 앱이 정하는 선택 틴트(primary)·비선택 틴트(text2)는 막대 위에서 4.5:1 이상이에요. 틴트를 지정하지 않으면 iOS 기본 회색 라벨이 2.8~3.3:1이라 **비선택 틴트를 반드시 지정**해요(표의 참고 행).
4. 날짜 위젯 6가지 프리셋은 파스텔 면 + 갈색 글자로 모두 6.8:1 이상이에요.
5. **마스코트 조합 추가**(소유자 제공 캐릭터 도입): 마스코트 가장자리(윤곽선 또는 림)와 앱 배경·카드 면·약한 면, 방 벽·바닥의 5쌍을 8가지 조합 모두에 더했어요. 결과는 모두 3:1 이상이고, 어두운 앱·밤 방에서는 크림 림이, 밝은 앱·낮 방에서는 갈색 윤곽선이 가장자리를 만들어요. 얼굴 선·띠·몸통 톤의 쌍은 아래 "마스코트" 절에 있어요.
