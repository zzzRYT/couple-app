# design/wordmark — 아룸 워드마크 (01 Gaegu)

앱 아이콘 A의 아루미 얼굴과 이름 글자를 묶은 워드마크예요. 두 후보(01 Gaegu, 02 Noto) 중 **소유자가 01 Gaegu를 골랐어요**(2026-11-10, 앱의 손글씨 글자 톤과 맞아서). 얼굴은 `../mascot/vector/icon_face_A.svg`의 경로를 그대로 쓰고, 글자는 앱에 포함된 **Gaegu Bold**의 실제 글리프를 외곽선으로 바꾼 거예요. 새로 그린 그림은 없어요. 권리 상태는 마스코트·앱 아이콘과 같아요(`../icon/README.md`).

## 파일

| 폴더 | 내용 |
|---|---|
| `svg/` | 외곽선 패스만으로 된 SVG(외부 글꼴·이미지·링크 없음) |
| `png/` | 투명 PNG `@1x`·`@2x`·`@3x` |
| `OFL.txt` | Gaegu 글꼴 라이선스(SIL Open Font License 1.1) 사본 |

파일 이름은 `{언어}-{변형}`이에요.

| 변형 | 용도 | 캔버스 높이 |
|---|---|---|
| `light` | 종이색 같은 밝은 배경 | 28pt (28/56/84px) |
| `dark` | 어두운 배경 | 28pt |
| `mono` | 밝은 배경에 갈색 한 색. 어두운 배경에 쓰려면 모든 경로를 밝은 한 색으로 바꿔요 | 28pt |
| `small-light`, `small-dark` | 저작권 줄 전용 **글자만**(얼굴 없음) | 12pt (12/24/36px) |

앱은 `ko-light`·`ko-dark`·`en-light`·`en-dark`의 PNG를 `apps/mobile/assets/brand/wordmark-*.png`(1x는 접미사 없음)로 번들해요.

## 사용 규칙

- **언어**: 한국어는 `ko`(아룸), 그 밖의 모든 언어는 `en`(Aroom)이에요. 바뀌는 건 워드마크뿐이고 문장 속 앱 이름은 그대로예요(일본어 문장과 스토어의 アルーム 포함).
- **테마**: 밝은 화면은 `light`, 어두운 화면은 `dark`. 한 색이 필요하면 `mono`.
- **크기**: 기본형은 28pt 높이로 써요. 얼굴이 있는 기본형·단색형은 28pt보다 작게 쓰지 않아요.
- **여백**: 기본형 주변에 최소 7pt(캔버스 높이의 1/4)를 비우고 사진·버튼·화면 가장자리와 겹치지 않게 해요. 12pt 글자형은 최소 3pt.
- **12pt 저작권 줄**: `small-*`는 글자만 있어요(12pt에서는 얼굴의 눈과 입이 남지 않아요). 저작권 문구 자체는 `© 2026 jinjinstar`처럼 **실제 텍스트**로 옆이나 아래에 둬요. Gaegu의 12pt 한글은 획이 뭉쳐서 약하니 가능하면 `en-small-*`이나 더 큰 크기를 써요.
- **접근성**: 워드마크 이미지에는 현재 언어의 앱 이름(`app.name`)을 접근성 이름으로 붙여요.

출처 보고서와 후보 비교는 작업 기록(cpl-wordmark)에 있고, 이 폴더의 파일은 납품본을 그대로 복사한 거예요.
