# design/later/history — 기록(버전 목록 · 복구) 포함 설계

방을 꾸민 버전을 목록으로 보고, 이전 버전을 골라 복구하는 **기록 기능**의 설계예요. 1차(V1)에서는 이 기능을 뺐고(탭 3개: 홈·방·설정), 나중에 확인하고 넣을 수 있도록 **따로 모아 두었어요**. 상태는 *보류, 채택하면 바로 쓸 수 있게 준비됨(deferred, ready to adopt)*이에요.

V1은 그대로예요. 이 폴더는 V1의 `screens.md` 화면 수, `i18n-copy.md` 키 수(587), `assets-manifest.csv` 수에 **들어가지 않아요**. V1 화면과 문서는 이 폴더를 참조하지 않고, `design/README.md`와 `design/handoff.md`만 "보류, 채택 준비됨"으로 가리켜요.

## 캔버스 보드

캔버스의 마지막 섹션(V1 보드와 캐릭터 섹션 뒤)에 **'V1 이후 · 기록 포함 버전 (1차에서는 쓰지 않아요)'** 라벨을 단 보드 4장이 있어요. 파일은 `design/canvas/project/L-*.dc.html`이에요.

| 보드 | 내용 |
|---|---|
| `L-S11-history` | 목록 · 선택/상세 · 복구 확인 · 복구 중 · 복구 성공 · 상대 점유 중 복구 불가 · 복구 실패 · 빈 기록 · 읽을 수 없는 이전 버전. 구역: iOS 낮 방+밝은 앱 ko / Android 밤 방+어두운 앱 ko / 영어·일본어·긴 문구 / 고대비·글자 200% |
| `L-S25-tab-history` | 기록 탭 첫 실행 · 보통 · 로딩 · 오프라인 · 오류 · 상대가 꾸미는 중 · 푸시/다이얼로그 |
| `L-S24-room-with-history` | 방 탭 상태 전부를 **기록 바로가기가 있는 도구 막대**(꾸미기·기록)와 **4탭 바**로 그린 것 |
| `L-S27-navigation-4tabs` | 4탭 구조와 이동 규칙 |

- 보드의 모든 프레임은 4탭 바를 쓰고, `L-S24`는 방 도구 막대가 꾸미기·기록 2개인 버전이에요. 세 화면 보드(L-S11·L-S24·L-S25)는 모두 같은 네 구역(iOS 낮 방+밝은 앱 ko / Android 밤 방+어두운 앱 ko / 영어·일본어·긴 문구 / 고대비·글자 200%)으로 그렸어요.
- 보드의 프레임 캡션과 화면 ID는 앞에 `L-`을 붙여 V1과 겹치지 않게 했어요. V1 화면 번호는 바꾸지 않았어요(V1에서 S11·S25는 비어 있음).
- 이 보드들은 기록을 뺀 직후의 V1 사양(방향 A, 마스코트, 홈 배경 사진, 움직임)과 같은 값으로 그렸어요.

## 알려 둘 한계

- 이 보드들은 기록을 뺀 직후의 모습을 그대로 보관한 것이라 **채택 시점의 최신 V1 화면과 어긋날 수 있어요**(예: 이후 바뀌는 문구, 홈 화면). 채택할 때 `apply-later.md`의 순서대로 V1 최신 보드에 맞춰 다시 확인해요.
- 이 보드들은 1차에서 "되돌리기는 열린 대화 안에서만, 적용 후 되돌리기 없음"으로 정한 뒤의 도구 막대(꾸미기·기록)로 맞췄어요. 기록을 채택하면 기록의 복구가 적용한 뒤 되돌리는 첫 번째 방법이 돼요(`apply-later.md` 5절).
- 방 안 마스코트 움직임 · 순환 로더는 L 보드에도 적용돼 있어요(캔버스에서만 재생, PNG는 정지 프레임).
- 영어·일본어 문구는 원어민 검수 전이에요. 실기기·스크린 리더는 확인하지 못했어요.
