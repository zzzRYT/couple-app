# components.md (V1 이후 · 기록 포함 버전)

V1과 달라지는 컴포넌트 두 가지예요.

## 탭 바 (시스템, 4개)

- 항목 4개: 홈 · 방 · 기록 · 설정 (`tab.home`, `tab.room`, `tab.history`, `tab.settings`). 배지 없음(알림 기능 없음).
- 접근성: 막대 `a11y.tabbar`, 항목 `a11y.tab` ("{name} 탭, 4개 중 {n}번째, 선택됨"). 시스템이 `tablist/tab` 역할과 선택 상태를 줘요.

나머지(틴트 · 큰 글자 · 보호 영역 · 숨김 규칙)는 V1 `components.md` §1.1과 같아요.

## 방 도구 막대 (기록 바로가기 포함)

(직접 그림 · 방 화면의 **자기 도구 막대**, 위쪽)
- 항목: **꾸미기**(주 버튼, `room.ctl.decorate`), **기록**(`room.ctl.history`, 기록 탭으로 가는 바로가기). 되돌리기는 도구 막대에 없고 꾸미기 시트 안에만 있어요(1차 결정).
- 변형: 보통(2개 한 줄) / 글자 ≥160%(꾸미기 한 줄 + 기록 한 줄, 2단). 라벨 글자는 160%에서 멈춰요(자동 축소가 아니라 확대 상한).
- 상태: 기본 / 비활성(점선 윤곽선 + 보조 글자) / 상대 점유 중 — 꾸미기가 **지켜보기**(`room.watch`, 보조 스타일, 눈 아이콘)로 바뀌어요.
- 윤곽선 색은 **방의 낮밤**을 따라가요(낮 `#4A3426` · 밤 `#E8D3BC` · 고대비 `#1F140D` / `#FFF0DC`, 3px). 앱 모드와 무관하게 경계가 3:1 이상.
- 접근성: 컨테이너 `a11y.toolbar`(툴바), 버튼 이름 `a11y.decorate` / `a11y.history`. 최소 터치 48 × 48(높이 52).
- 레이어: 장면 캔버스 **밖** 네이티브 뷰. 꾸밈 프롬프트가 위치·이름·동작을 바꿀 수 없어요.
