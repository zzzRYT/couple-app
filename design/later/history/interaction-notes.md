# interaction-notes.md (V1 이후 · 기록 포함 버전)

V1의 `design/interaction-notes.md`와 **다른 부분만** 모았어요. 나머지(점유, 키보드, 오프라인, 동기화 등)는 V1 문서와 같아요.

## 1. 내비게이션 구조 (4탭)

```
앱 시작
 ├─ 로그인 안 됨 ─ S01 온보딩 ─ S02 로그인 ─ (공간 없음) S03 공간 생성 ─ S04 초대 코드
 │                                         └ (코드 있음) S05 코드 입력 ─ 참여
 ├─ 공간 종료됨 ─ S14 종료 화면(복구 기한·복구)  ※ 탭 구조 대신
 └─ 활성 공간 ─ [시스템 탭 바]
        ① 홈 ─ 홈 루트(S06)
        │        ├ 초대 코드 보기(푸시, 탭 바 숨김) → S04 코드 화면
        │        ├ 날짜 수정(시트)
        │        └ 우리 방 열기 → ② 방 탭으로 전환
        ② 방 ─ 방 루트(S07)
        │        ├ 꾸미기(모달 시트, 탭 바를 덮음) → S08 / S09
        │        └ 기록(바로가기) → ③ 기록 탭으로 전환
        ③ 기록 ─ 기록 루트(S11)
        │        ├ 버전 상세(푸시, 탭 바 숨김) → 복구 확인(다이얼로그)
        │        └ (빈 기록) 방 꾸미러 가기 → ② 방 탭으로 전환
        ④ 설정 ─ 설정 루트(S13)
                 ├ 언어 · 시간대(시트)
                 ├ AI 처리 동의 관리(푸시) / 동의 화면 S12(모달)
                 ├ 글꼴·오픈소스 라이선스(푸시)
                 ├ 문의 · 신고(푸시) → S15
                 └ 공간 종료(푸시) → S14 확인 → 종료 화면
```

### 1.1 탭을 이렇게 정한 이유 (제안)
- 홈 · 방 · 기록 · 설정 4개. 스펙 범위(D-day, 꾸미는 방, 복구, 설정)를 그대로 4개 목적지로 나눈 거예요. 캘린더·할 일·사진·알림이 없어서 5번째 탭이 필요 없고, 탭이 4개를 넘으면 한국어·일본어 라벨이 좁아져요.
- **기록 탭을 따로 둔 이유**: 스펙 FR-013이 "이전에 저장된 꾸밈도 복구"를 별도 기능으로 요구하고, 방 화면의 도구가 줄어도 한 번에 닿아요. 방 도구 막대에도 같은 곳으로 가는 바로가기(기록)를 둬요. 대안: 기록 탭을 빼고 방 도구 막대의 기록만 두면 3탭(홈·방·설정).


### 1.2 탭 바 표시 규칙 (달라지는 줄)

| 화면 종류 | 탭 바 |
|---|---|
| 탭 루트 4개 | 보임 |
| 푸시된 상세(버전 상세, 라이선스) | 숨김 |

뒤로 가기 규칙은 V1과 같아요(탭 루트에서 뒤로 = 홈 탭, 홈에서 뒤로 = 앱 나가기, 선택된 탭 다시 누르기 = 맨 위 / 루트로).

## 4. 꾸미기 흐름 (달라지는 줄)

| 단계 | 점유자(나) | 상대 |
|---|---|---|
| 기록 복구 | 기록 탭 → 버전 상세(미리 보기) → "이 버전으로 복구" → 확인 → **새 버전**으로 쌓이고 현재 방이 기록에 남아 다시 돌아올 수 있어요. 복구도 점유가 필요하다고 가정(열린 질문) | 같음 |

## 8. 오류 (달라지는 줄)

| 상황 | 동작 |
|---|---|
| 장면 데이터 복구 오류 | 방 위에 안내 + "이전 버전 보기"로 기록 탭의 복구로 연결 |
| 버튼 중복 탭 | 제출·적용·복구는 진행 중 비활성(로딩 상태)이고 서버는 멱등 키로 이중 처리를 막아요 |

## 10. 접근성·움직임 (달라지는 줄)

- **스크린 리더**: 읽기 순서 = 도구 막대(꾸미기 → 기록) → D-day 위젯 → 마스코트 → 시스템 탭 바. 장식 소품은 건너뛰어요. 상태 변화는 한 번만 알려요(점유 변경, 미리 보기 생성, 적용, 오류).
- 상태별 규칙: 읽기 전용(오프라인)에서도 걷기는 계속해도 되지만(장식), 꾸미기 미리 보기·적용 확인·되돌리기 확인 중에는 **멈춰요**(제안: 방이 바뀌는 순간에 시선이 분산되지 않게). 로딩·복구 오류·보호 영역 표시 화면에는 마스코트가 나오지 않거나 정지 상태예요. 축소 보기(방 카드, 프롬프트 위 방 축소, 기록 섬네일)는 늘 정지 포즈예요.
