V0 흐름 · 개요 (커플 D+Day V1)

방 꾸미기는 다음 버전으로 미루고, 두 사람이 연결해서 D+Day와 기념일을 보고 위젯으로 확인하는 앱을 V1으로 먼저 내요. 이 페이지는 전체 흐름, 범위, 날짜 규칙, 누가 무엇을 바꾸는지를 모았어요.

흐름

같은 ID가 각 페이지의 프레임 이름이에요. 기존 보드에 이미 있는 상태(로그인 시트, 초대 오류 등)는 다시 그리지 않고 점선 칸으로 가리켜요.

실선 칸 = 이번에 그린 V0 프레임점선 칸 = 기존 보드 그대로 재사용파란 칸 = 시스템 · 앱 밖붉은 칸 = 끝나는 동작

  • F01 로그인(Apple 우선 + 이메일·비밀번호, 비밀번호 재설정, 비밀번호로 하는 계정 삭제 본인 확인) · F02 커플 연결(공간 만들기 + 사귄 날, 초대 코드, 코드 입력) · F03 홈 D+Day
  • F04 자동 기념일(50·100·150·200·300일, 매년 주년) · F05 생일(각자 입력, 둘 다 넣으면 공개) · F06 시즌(빼빼로데이 11/11, 크리스마스 12/25)
  • F07 직접 추가 기념일(두 사람 공유, 추가·편집·삭제) · F08 기념일 목록·상세 · F09 당일 축하 카드

  • 자세한 ID 표와 열린 질문: data/cpl-v0-design/v0-scope.md

상호작용 규칙

계정 · 자격 증명 (2026-11-06 오너 결정)

  • 이메일 계정: 이메일 + 비밀번호로 로그인. 삭제 확인도 비밀번호(V0-del-email). 잊으면 재설정 메일, 메일 전에는 문의.
  • Apple 계정 · 비밀번호 없음: Apple로만 로그인. 삭제 확인은 Apple 재로그인(V0-set-delete 그대로). 정상 상태예요.
  • Apple 계정 · 앱 비밀번호 있음: Apple로 로그인하거나, 계정의 이메일 주소 + 앱 비밀번호로 로그인. 삭제 확인은 앱 비밀번호(V0-del-pw). 잊거나 잠기면 Apple 재로그인으로 대신해요(메일 불필요).
  • Apple 로그인 뒤 비밀번호는 안내예요(V0-auth-setpw-prompt, "나중에 할게요"). S02-setpw의 "건너뛰기 없음"을 대체해요.
  • 기존 TestFlight 사용자: 모두 비밀번호 없는 Apple 계정으로 그대로 이어져요. 업데이트 뒤 처음 열 때 안내(V0-auth-setpw-sheet)를 한 번 보고, 건너뛰면 설정에서 만들 수 있어요.
  • Apple 계정을 지우면 비밀번호로 확인했어도 Apple 토큰을 꼭 해지해요(App Store 규칙). 서버에 토큰이 없으면 V0-del-apple-more로 Apple 확인을 한 번 더 받아요.
  • 비밀번호는 인증 제공자 서버에 해시로만 저장돼요. Apple 계정 암호는 앱에 들어오지 않아요.
  • 카카오는 V0에 없어요.
REVIEW

Apple 계정의 이메일 로그인 (검토 필요)

  • 앱 비밀번호를 만든 Apple 계정은 계정의 이메일 주소 + 앱 비밀번호로 로그인해요.
  • 이메일을 가린 계정의 주소는 @privaterelay.appleid.com이라 외울 수 없어요. 앱이 보여 주고 복사하게 했지만 다른 기기에서는 불편해요.
  • 재설정 메일이 가림 주소로 가려면 보내는 도메인을 Apple에 등록해야 해요. Apple 계정은 메일 없이 Apple 재로그인으로 해결돼요.

날짜 세기 (기존 S06 · 스펙 규칙 그대로)

  • 사귄 날 당일 = 1일째 = D+1. 달력 날짜 차 + 1, 공간의 IANA 시간대(기본 Asia/Seoul) 자정 기준.
  • N일 기념일 = 사귄 날 + (N − 1)일. 기존 서버 목록에는 150일이 없어서 V1 백엔드에서 더해야 해요(500·1000일은 오너 목록에 없어 V1에서 빠짐 — 열린 질문).
  • 주년 = 같은 달력 날짜(365일 단위 아님) → 1주년은 366일째. 2월 29일 시작은 평년 2월 28일. 같은 날이면 주년이 우선.
  • 생일은 양력 월·일(연도 선택), 2월 29일 생일은 평년 2월 28일.

누가 무엇을 고치나

  • 사귄 날·시간대: 두 사람 누구나, 확인 후 두 사람에게 적용. 상대 홈에 "하루님이 사귄 날을 바꿨어요" 띠.
  • 직접 추가 기념일: 두 사람 누구나 추가·편집·삭제(삭제는 확인). 동시 편집은 버전 확인 후 충돌 안내.
  • 생일·이름: 본인만. 상대 생일은 두 사람 모두 넣었을 때만 보여요.
  • 자동 기념일: 아무도 못 고침. 알림만 각 기기에서 종류별로.
  • 알림·언어·화면 모드: 이 기기에만.

상대가 연결을 끊으면

  • 연결 끊기 = S14 공간 종료와 같은 결과. 두 사람 모두 공간을 잃고 사귄 날·직접 추가 기념일·생일 공유가 지워져요(되돌릴 수 없음).
  • 끊긴 쪽은 다음에 앱을 열 때(열려 있으면 바로) V0-state-ended를 보고 "새로 시작하기"로 다시 연결할 수 있어요.
  • 두 기기 모두 예약 알림과 위젯 데이터를 지워요. 상대가 계정을 삭제해도 같아요.

시간대 · 하루 경계

  • D+N·D-n·축하 카드·알림 시각은 모두 공간 시간대 기준이에요. 여행 중이어도 서울 자정에 하루가 넘어가요.
  • 공간 시간대는 만든 사람 기기의 시간대로 정하고 설정에서 바꿀 수 있어요(두 사람에게 적용).
  • 서버가 계산하고 앱·위젯은 마지막으로 받은 사귄 날·시간대로 같은 규칙을 다시 계산해요(오프라인에서도 날짜는 넘어가요).

동기화 · 오프라인

  • 앱이 열려 있는 동안 Realtime 힌트 → 다시 불러오기. 닫혀 있던 폰은 다음에 열 때 반영돼요(알림·위젯 다시 맞춤 포함).
  • 불러오기는 전부 아니면 없음(2026-11-01 규칙). 오프라인은 마지막 데이터로 읽기만.
