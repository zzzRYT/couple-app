마일스톤 축하 · 이 화면 모음의 약속

일수 마일스톤(50일·100일·200일·300일·500일·1000일)과 주년(함께한 날짜와 같은 달력 날짜)에 **앱을 열었을 때** 마스코트(아루미)가 홈 카드와 방 말풍선으로 축하하고, 원하면 앱이 준비한 기념 방 꾸미기 제안을 기존 미리 보기 → 적용 흐름으로 볼 수 있어요. 알림은 **옵트인 · 기기에 예약하는 로컬 알림**만 있어요(서버 푸시 없음, 탭 바 배지 없음). 방은 구성원이 확인하고 적용해야만 바뀌어요.

규칙

항목규칙(결정됨)
계산서버가 방의 시간대 기준으로 계산해요. 일수 마일스톤은 기존 D-day 규칙(함께한 날짜 당일 = 1일째), 주년은 함께한 날짜와 같은 달력 날짜(매년)예요. 기기 시계를 믿지 않아요.
윤일 규칙2월 29일에 시작했다면 윤년이 아닌 해의 주년은 2월 28일로 계산해요.
같은 날 겹침주년과 일수 마일스톤이 같은 날이면 축하는 하나만, 주년이 우선이에요. 7일 안에 여러 개가 있으면 가장 최근 날짜 하나만 보여 주고 같은 날이면 우선순위(주년 > 일수)를 따라요.
언제 보이나구성원이 앱을 열었을 때(홈 카드)와 방 탭을 열었을 때(말풍선). 알림을 켠 기기는 당일 오전 9시에 알림 배너도 받아요(아래 표).
커플당 한 번한 마일스톤은 커플당 한 번만 축하해요(서버에 기록). 두 사람은 각자 한 번씩 봐요. 한 사람이 닫아도 상대는 아직 안 본 거예요.
놓친 경우(주년 포함)마일스톤 당일을 포함해 7일 안에 처음 열면 "늦은 축하" 문구로 보여 줘요. 7일이 지나면 보이지 않고 "지난 것"으로만 기록해요. 알림을 놓쳐도 이 규칙은 그대로예요.
닫기카드의 ✕ 또는 말풍선의 ✕ = 이 구성원에게는 본 것으로 처리해요(한쪽만 닫아도 둘 다 사라져요). 오프라인에서 닫으면 기기에 저장했다가 연결되면 한 번만 전달해요.
함께한 날짜를 고쳤을 때이미 기록된 마일스톤은 날짜가 바뀌어도 다시 축하하지 않아요. 단 고친 날짜로 계산한 마일스톤 날이 아직 오지 않았다면 기록을 지우고 새 날짜에 한 번 더 축하해요. 이미 지난 날짜로 바뀌면 기록이 없는 마일스톤만 "놓친 경우" 규칙을 따라요. 예약해 둔 알림은 다시 예약해요.
두 사람이 모두 참여한 공간에서만상대를 초대하는 중(초대 대기)에는 보이지 않고 알림도 예약하지 않아요.
오프라인·서버 오류마지막으로 받은 상태만 보여 주고 새 축하는 만들지 않아요. 이미 예약된 알림은 기기가 그대로 보내요. 서버 오류는 축하만 숨기고 홈·방·꾸미기에는 영향이 없어요.
공간 종료·복구종료 중에는 보이지 않고 예약 알림도 취소해요. 30일 안에 복구하면 기록이 돌아오고 알림을 다시 예약해요.

축하 구성과 움직임

요소앱 고정 규칙
홈 카드홈 커버 아래, 방 카드 위에 한 장. 마스코트(cheer = 신나게 인사) + 제목 + 본문 + 버튼 1개(기념 방 꾸미기 보기) + 닫기. 앱 면(크림 종이) 위라서 배경 사진과 상관없이 같은 대비예요.
방 말풍선방 탭에서 마스코트 머리 위에 크림 종이 말풍선 한 개. 짧은 문구 + ✕. 보이는 동안 마스코트는 움직임 순서를 멈추고 cheer로 서요. 닫으면 다시 돌아다녀요.
움직임(고정)마스코트가 2.4초 주기로 통통 뛰고(최대 16px), 반짝이 두 개가 1.4초 주기로 깜박여요. 앱이 정한 값이고 프롬프트·장면 데이터로 바꿀 수 없어요. 카드·말풍선이 열려 있는 동안 반복하되 10초 뒤 정지해요(제안).
동작 줄이기모든 움직임을 멈추고 cheer 정지 포즈 + 정지 반짝이만 보여요.
문구고정 번역 템플릿(ko/en/ja, 키 milestone.*). AI 호출 없음. 글자 130% 이상에서는 카드가 세로로 쌓여요.
접근성카드는 영역 이름 "{라벨} 축하 카드", 말풍선은 상태(status) 낭독, 닫기 버튼 이름 있음, 터치 44pt 이상.
알림에서 열었을 때알림을 누르면 앱이 홈으로 열리고 축하 카드가 바로 보여요(아래 "알림에서 연 모습" 프레임). 이미 본 마일스톤이면 카드 없이 홈만 열려요.

기기 예약 알림(옵트인) 규칙

항목규칙(결정됨)
무엇기기에 예약하는 로컬 알림(옵트인). 서버 푸시(원격 알림)는 쓰지 않아요 — 푸시 토큰도 서버에 저장하지 않아요.
언제 묻나첫 축하 카드를 닫은 뒤 한 번 사전 안내 시트(S28 프레임), 또는 설정 > 알림에서. 앱을 처음 켤 때는 절대 묻지 않아요. "다음에"를 누르면 설정에서만 다시 켤 수 있어요.
권한시트에서 "알림 켜기"를 누르면 그때 OS 권한 창이 떠요(iOS 알림 권한, Android 13+ POST_NOTIFICATIONS). 거절하면 설정 행이 "기기에서 알림이 꺼져 있어요" + 켜는 방법 안내로 바뀌어요.
시각마일스톤 당일 오전 9시(방의 시간대). 놓친 날은 따로 보내지 않아요.
문구(잠금 화면 안전)제목은 앱 이름, 본문은 "아루미가 축하할 일이 생겼어요." 한 가지(3개 언어). 이름·날짜·일수·주년 수를 넣지 않아요.
예약 규칙구성원마다 자기 기기가 다가오는 마일스톤을 예약해요(서버가 목록 계산 → 기기가 가장 가까운 3개를 OS에 예약, iOS 대기 알림 64개 한도는 문제 없음). 알림 식별자 = 마일스톤 키라서 같은 마일스톤이 두 번 예약되지 않아요.
다시 예약함께한 날짜 변경 · 방 시간대 변경 · 앱 업데이트 · 앱을 열 때(목록 확인) → 다시 예약. 취소: 공간 종료·연결 끊기, 로그아웃, 알림 끄기, 상대가 나가 공간이 끝남.
누르면앱이 홈으로 열리고 축하 카드가 보여요. 알림을 받았어도 앱 안 규칙(커플당 한 번 · 구성원마다 한 번 · 7일)은 그대로라 카드를 닫으면 본 것으로 기록돼요.
중복·누락알림은 당일 1회. 놓치면 앱을 열었을 때 7일 안에 "늦은 축하"로 보여요. 알림을 켜지 않은 구성원도 앱 안 축하는 받아요. 한 기기만 켜도 돼요(상대 기기는 따로).
설정 행설정 > 알림 > 마일스톤 알림 토글. 상태: 꺼짐(이 기기에만 적용) / 켜짐(오전 9시) / 기기에서 꺼져 있음(기기 설정 열기). 이 기기에만 적용돼요.
스토어·개인정보알림 권한 용도를 사용 목적 문구에 적어요(기념일 알림). 알림 문구에 개인정보가 없고 서버에 토큰을 저장하지 않으며 마케팅 알림이 아니라는 점을 심사 메모에 써요. 개인정보 처리방침 문구는 법률 검토 필요.

방 꾸미기 제안(앱 프리셋)과 에셋 예산

항목값
구성(일수)카탈로그 기존 오브젝트: 케이크 1 · 풍선 1 · 리본 1 · 반짝이 2 = 소품 5개 + 기념 문구 1개("우리 100일")
구성(주년)위 5개 + 선물 1개 = 소품 6개 + 문구 1개("우리 1주년")
새 카탈로그 오브젝트0개 필요. 카탈로그는 24종 그대로(24~36 범위의 아래 끝). 가랜드 배너는 만들지 않아요(결정권자가 답하지 않아 보류)
방 한도방 오브젝트 16개(마스코트 1개 포함)와 문구 3개 한도를 지켜요. 자리가 모자라면 우선순위(케이크 → 리본 → 풍선 → 반짝이 → 선물)대로 가능한 만큼만 놓고 "소품 N개만 놓았어요"를 보여 줘요. 자리가 0이면 입구가 비활성이고 이유를 알려요. 문구가 이미 3개면 문구만 건너뛰어요.
배치기존 배치 검증기가 보호 영역(날짜 위젯·도구 막대·탭 바)을 피해 놓아요. 기존 소품 위치는 바꾸지 않아요.
흐름입구 → (상대가 점유 중이면 막힘) → 점유 시작 → 미리 보기(S09, "{라벨} 제안" 뱃지, 변경 요약, AI 없음 안내) → 적용 확인 "적용한 뒤에는 되돌릴 수 없어요" → 적용. 자동 적용은 절대 없어요.
AI 사용없어요. 해외 AI 동의가 필요 없고 하루 3회 한도에도 들어가지 않아요.
문구 언어기념 문구는 제안을 시작한 구성원의 앱 언어로 저장돼요(직접 쓴 문구처럼 번역하지 않아요).
