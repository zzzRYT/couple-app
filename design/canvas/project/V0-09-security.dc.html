V0-09 로그인·보안 · 계정 삭제 확인

설정의 로그인·보안, 비밀번호 바꾸기, 계정 삭제 본인 확인이에요. S13-security·S13-pw-change·S13-delete-reauth*를 V0 모양으로 옮겼고, 비밀번호가 없는 Apple 계정과 이메일 계정을 함께 그렸어요.

로그인·보안

설정 › 계정 › 로그인·보안(V0-set-main-2). 계정이 가진 자격 증명에 따라 세 가지 모습이에요.

비밀번호 바꾸기

이메일 계정은 같은 화면에 제목만 "비밀번호 바꾸기"예요. 저장 전에 지금 비밀번호를 확인해요.

계정 삭제 · 비밀번호로 본인 확인

V0-set-delete에서 "계정 삭제하기"를 누르면 올라오는 시트예요. 비밀번호가 없는 Apple 계정은 이 시트 없이 V0-set-delete의 "Apple로 다시 로그인해 확인" 그대로예요. 삭제 중·오프라인·실패·완료는 S13-delete-* 그대로예요.

영어 · 일본어 (주요 화면)

번역으로 길어진 문구가 잘리지 않고 줄바꿈되는지 봐요.

규칙

누가 어떤 자격 증명을 쓰나

  • 이메일 계정: 이메일 + 비밀번호로 로그인. 삭제 확인도 비밀번호(V0-del-email). 잊으면 재설정 메일, 메일 전에는 문의.
  • Apple 계정 · 비밀번호 없음: Apple로만 로그인. 삭제 확인은 Apple 재로그인(V0-set-delete 그대로). 정상 상태예요.
  • Apple 계정 · 앱 비밀번호 있음: Apple로 로그인하거나, 계정의 이메일 주소 + 앱 비밀번호로 로그인. 삭제 확인은 앱 비밀번호(V0-del-pw). 잊거나 잠기면 Apple 재로그인으로 대신해요(메일 불필요).
구현 확인 필요

Apple 토큰 해지 (App Store 규칙)

  • Apple 계정을 지우면 어떤 방법으로 확인했든 Apple 토큰을 꼭 해지해요. 비밀번호 확인이 해지를 대신하지 않아요.
  • 해지에는 Apple이 준 토큰이 필요해요. 지금 서버는 삭제 때 Apple 재로그인의 authorizationCode로 토큰을 받아요. 비밀번호로 확인하면 이 코드가 없어요.
  • 그래서 Apple 로그인 때 토큰을 봉인해 보관하고, 없으면 V0-del-apple-more로 Apple 확인을 한 번 더 받아요.

잠금 · 실패

  • 삭제 확인과 비밀번호 바꾸기는 로그인과 같은 규칙이에요: 5회 틀리면 10분 잠금, 서버가 세요.
  • Apple 계정은 잠겨도 Apple 재로그인으로 계속할 수 있어요. 이메일 계정은 10분을 기다리거나 비밀번호를 재설정해요.
  • 삭제 중·오프라인·실패·완료 후 로그아웃은 S13-delete-progress·offline·fail·done 그대로예요. 오프라인이면 시트를 열기 전에 막혀요.

이번에 달라진 기존 화면

  • V0-set-main-2: "Apple로 로그인함" 행이 "로그인·보안" 행이 됐어요. 오른쪽 값에 같은 문구가 남고, 이메일 계정은 "이메일로 로그인함"이에요.
  • V0-set-delete: 비밀번호가 없는 Apple 계정의 화면으로 그대로 써요. 비밀번호가 있는 계정은 아래 버튼이 "계정 삭제하기"이고 눌렀을 때 본인 확인 시트가 올라와요.
  • S13-security의 "메일 발송 필요" 표시는 V0-sec-forgot(Apple, 메일 불필요)과 V0-del-email-nomail로 나눴어요. 카카오·제안 표시는 뺐어요.
