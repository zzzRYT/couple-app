V0-01 시작 (로그인 · 연결)

V1의 첫 경험이에요. Apple 로그인(우선)과 이메일 로그인(V0-08), 사귄 날 입력, 내 이름과 생일, 그리고 S03~S05의 초대·참여 동작을 그대로 써요. 만든 초대 코드는 홈에서도 계속 보여요(PR 26).

iOS · 밝은 앱 · 한국어

만드는 사람: 소개 → 시작 방법 → 사귄 날 → 이름·생일 → 초대 코드 → 홈(상대 대기). 초대받은 사람: 소개 → 시작 방법 → 코드 입력 → 참여 확인 → 이름·생일 → 연결 완료 → 알림 안내.

iOS · 어두운 앱 · 한국어

영어 · 일본어 (주요 화면)

번역으로 길어진 문구가 잘리지 않고 줄바꿈되는지 봐요.

규칙 · 재사용

재사용하는 기존 보드

  • Apple 시스템 시트·취소·오류: S02 그대로 (S02-apple · S02-cancel · S02-error). 이메일 로그인·계정 만들기·비밀번호는 아래쪽 V0-08 보드에 있어요. 카카오와 인증 코드 로그인은 없어요.
  • 초대 코드 만료 임박·만료·재발급·공유 시트·복사 토스트·네트워크 오류: S04 그대로.
  • 코드 만료·사용됨·틀림·인원 초과·이미 다른 공간·네트워크 오류: S05 그대로.
  • 뒤로 가기는 PR 24의 공통 "<" 컨트롤, 48pt.

V0에서 달라진 점

  • S01 3장 소개를 1장으로 줄였어요. 방·프롬프트 소개는 빠져요.
  • "함께한 날짜" 대신 "사귄 날"이라고 불러요. 1일째(D+1) 규칙을 입력 화면에서 바로 보여 줘요.
  • 공간 만들기 다음에 이름·생일을 받아요. 생일은 건너뛸 수 있고, 태어난 해는 선택이에요(양력).
  • 초대받은 사람은 코드 확인 → 참여 → 이름·생일 → 연결 완료 순서예요.
  • 알림 권한은 앱 첫 화면에서 묻지 않아요. 연결이 끝난 직후 사전 안내를 한 번 보여 주고, "알림 켜기"를 눌렀을 때만 iOS 권한 창을 띄워요.

접근성 · 모션

  • 모든 버튼과 칸은 48pt 이상, 위 47 · 아래 34 안전 영역을 비워요.
  • 연결 완료의 모피는 S29의 깡총(cpl-hop)·반짝임(cpl-twinkle)을 쓰고, 동작 줄이기가 켜지면 이 그림처럼 멈춰 있어요.
  • 글자 200%에서는 내용이 스크롤되고 아래 버튼은 고정돼요(S20 규칙).
