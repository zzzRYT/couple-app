S19 글꼴과 토큰

Inter + Noto Sans KR + Noto Sans JP(모두 OFL 1.1), 언어별 글자 크기·줄 높이, 방과 앱의 색 토큰, 간격·모서리·터치·안전 영역.

글꼴과 라이선스 — 방향 A(손글씨 + 차분한 본문)

1단계의 Gaegu + Gowun Dodum 조합을 3개 언어로 넓혔어요. Gaegu는 한글 2,350자(KS X 1001)만 있고 가나·한자가 없으며, Gowun Dodum은 한글 전체는 있지만 일본어가 없고 굵은 글씨도 없어요. 그래서 손글씨 제목용(display) / 차분한 본문용(body) / 굵은 글씨용(emph)을 나누고 일본어는 Yomogi + Zen Maru Gothic으로 받아요. 이 캔버스는 미리 보기 때문에 Google Fonts에서 글꼴을 불러오지만, 실제 앱은 원격 글꼴을 쓰지 않고 파일을 번들해요.

측정 방법: 각 TTF의 cmap을 읽어 한글 11,172자·KS X 1001 2,350자·가나·CJK 한자 개수를 세고, 이 앱의 모든 문구(한국어 452자 · 영어 79자 · 일본어 487자의 고유 글자)가 각 글꼴에 있는지 대조했어요. 서브셋 크기는 fontTools로 만든 TTF의 대략적인 값이고, 앱 스토어 압축 후 크기는 더 작아요(구현 때 EAS 산출물로 측정). 참고: Gaegu에는 가운뎃점(·)·말줄임표(…)가 없어서 손글씨 문구에는 이 기호를 쓰지 않고, 쓰면 본문 글꼴로 대체돼요. Noto Sans KR의 한자는 일본어 신자체 26자가 빠져 있어서 일본어 화면에는 Noto Sans JP를 써야 해요(화면 글꼴을 언어별로 분리하는 이유).

작은 글자와 큰 글자 규칙

  1. 손글씨는 토큰 크기가 20px 이상이고 굵은 제목류일 때만: 화면 제목, 큰 D-day 숫자, 마스코트 말풍선, 방 장면 속 문구, 빈 화면 제목. 20px 미만(본문·버튼·입력·칩·캡션·표·오류·동의·법적 문구·탭 라벨)은 무조건 본문 또는 굵은 글씨 글꼴이에요. 기준은 시스템 확대 전의 토큰 크기라서, 글자 크기를 키워도 본문 글꼴이 손글씨로 바뀌지 않아요.
  2. 손글씨 글꼴이 없는 글자(Gaegu에 없는 한글 음절·가운뎃점·말줄임표)가 문장에 하나라도 있으면 그 문장 전체를 본문 글꼴로 그려요(한 문장 안에서 글꼴이 섞이지 않게).
  3. 방 장면 문구는 최소 20pt로 제한해요(작은 손글씨 금지). 문구는 사용자가 쓴 그대로 보존하고 번역하지 않아요.
  4. 가장 큰 글자(200%): 손글씨 제목도 같이 커지고 줄바꿈으로 받아요. 줄 높이는 한국어 1.5, 영어 1.4, 일본어 1.6을 유지하고 자동으로 줄이지 않아요. 큰 D-day 숫자가 한 줄에 안 들어가면 "Day"와 숫자가 두 줄이 돼요. 방 도구 막대 라벨은 160%에서 멈추고 2단으로 바뀌어요(긴 누름 설명 제공). 시스템 탭 바는 OS가 정해요.
  5. 일본어 손글씨(Yomogi)는 굵기가 하나뿐이라 굵게 요청해도 인위적으로 굵히지 않아요(가짜 굵기 금지). 같은 이유로 Gowun Dodum도 굵게 쓰지 않고 굵은 글씨 글꼴로 바꿔요.
