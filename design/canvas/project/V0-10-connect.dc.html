V0-10 상대 연결 (홈 · 설정에서)

온보딩을 지난 뒤에도 상대와 연결하는 길이에요. 상대 연결 전이면 홈과 설정에서 들어오고, 코드를 보내거나 받은 코드를 넣어요. 코드를 받은 사람에게 이미 혼자 만든 공간이 있으면 그 공간을 닫고 상대 공간으로 옮긴다는 확인을 받아요. 연결되면 연결 동작은 사라지고 연결 상태만 보여요.

iOS · 밝은 앱 · 한국어

두 사람 다 혼자 공간을 만든 뒤에도(둘 다 "새로 시작하기") 앱 안에서 연결할 수 있어야 해요. 홈과 설정, 두 곳에서 들어와요. 오늘 = 2026년 11월 9일, 코드를 받은 사람(도담)은 이미 혼자 공간이 있어요.

iOS · 어두운 앱 · 한국어

영어 · 일본어

번역으로 길어진 문구가 잘리지 않고 줄바꿈되는지 봐요.

규칙

들어오는 길 (두 곳)

  • 홈: 상대 연결 전 카드(내 초대 코드) 아래에 "상대에게 코드를 받았어요"가 있어요. 누르면 V0-connect-code로 가요. 코드를 보내는 쪽은 지금처럼 카드의 복사·공유를 써요.
  • 설정 › 우리 › 상대: 연결 전이면 값 자리에 "연결하기 ›"가 보이고, 누르면 V0-connect(내 초대 코드 보내기 / 받은 코드 입력하기)로 가요. 내 초대 코드 보내기는 V0-start-invite(S04)를 그대로 열어요.
  • 연결된 뒤에는 홈 카드와 설정의 "연결하기"가 사라지고 "하루 · 연결됨"만 보여요. 누를 수 없고, 연결 동작이 두 번 나오지 않아요.

코드를 받은 사람에게 이미 공간이 있을 때

  • 한 사람은 활성 공간을 하나만 가질 수 있어서, 혼자 만든 공간이 있으면 받은 코드로 바로 참여할 수 없어요(서버 ALREADY_IN_SPACE). 그래서 확인(V0-connect-move)을 받은 뒤 지금 공간을 닫고 상대 공간에 참여해요. 서버 계약은 그대로예요(공간 종료 → 초대 수락).
  • 코드부터 확인해요. 만료·사용됨·틀림·인원 초과·네트워크 오류는 S05 오류를 그 자리에서 보여 주고, 코드가 유효할 때만 확인 화면이 떠요. 내가 만든 코드를 넣으면 공간을 닫지 않고 V0-connect-own을 보여 줘요.
  • 공간을 닫은 뒤 참여가 실패하면(그 사이 만료 등) 코드를 들고 시작 화면의 코드 입력(V0-start-enter)으로 가서 S05 오류를 그대로 보여 줘요. 다시 넣거나 새로 시작할 수 있어요.
  • 공간이 없는 사람(로그인 직후)은 지금처럼 V0-start-choose › 초대 코드가 있어요 › V0-start-found 순서예요. 확인 화면이 없어요.

재사용 · 결과

  • 코드 칸·붙여넣기·S05 오류: V0-start-enter 그대로. 연결 완료: V0-start-connected 그대로(두 사람 모두, 코드를 보낸 사람은 실시간으로 받아요).
  • 옮긴 뒤 홈은 상대 공간의 사귄 날·기념일로 바뀌고, 이 기기의 예약 알림과 위젯은 새 공간 기준으로 다시 맞춰요.
  • 모든 버튼과 행은 44pt 이상이에요. 확인 화면의 항목은 목록으로 읽혀요.
