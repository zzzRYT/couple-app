# design/canvas — 캔버스 원본

Claude Design 캔버스의 프로젝트 파일을 그대로 내보낸 것이에요(`project/` 아래).

| 파일 | 내용 |
|---|---|
| `project/canvas.json` | 보드 배치·제목 인덱스 |
| `project/Main.dc.html` | 개요. 상단에 **최종 방향 A**와 이유를 적었고 아래는 1단계 기록 |
| `project/A.dc.html` | **A 손그림 따뜻함**(1단계 시안, 최종 방향) — 수정하지 않았어요 |
| `project/B.dc.html` | B 평면 도형 — **대체된 참고 시안**(삭제하지 않음) |
| `project/S00-overview.dc.html`, `C01`~`C05`, `S01`~`S28` | 단계 2 보드: 개요 S00, **캐릭터 섹션 C01 캐릭터 개요 · C02 제스처 시트 · C03 팔레트·해부·규칙 · C04 배경·크기 · C05 하모나이즈 vs 원본**, 화면 S01~S16(S11 기록은 첫 버전에서 뺌, S17은 비어 있음, 마스코트는 C 보드로 옮김), 에셋 S18, 글꼴·토큰 S19, 접근성 S20, 긴 문구 S21, 컴포넌트 S22, 탭 S23·S24·S26(S25 기록 탭은 뺌), 탭 구조 S27, 마일스톤 축하 S28) |
| `project/L-S11-history`, `L-S24-room-with-history`, `L-S25-tab-history`, `L-S27-navigation-4tabs` | **V1 이후 · 기록 포함 버전(1차에서는 쓰지 않아요)**. 캔버스 마지막 섹션이고 V1 보드는 이 보드를 참조하지 않아요. 문서는 `../later/history/` |

- 각 `.dc.html`은 보드 하나의 전체 소스예요. 화면은 정적 마크업(인라인 스타일 + SVG)이라 브라우저에서 열어도 대부분 보여요. 다만 캔버스 런타임 스크립트(`support.js`)는 이 폴더에 없어서 편집·재생 기능은 Claude Design 안에서만 동작해요. 글꼴은 미리 보기용으로 Google Fonts를 불러와요(실제 앱은 번들).
- 화면은 이 저장소의 `design/` 문서와 같은 데이터에서 만들어져서 숫자(색·대비·키)가 일치해요.
- 보드 높이·위치는 렌더 측정값이에요.
- **마스코트 이미지**: 보드 안의 마스코트 `<img>`는 캔버스 에셋 저장소 주소(`/_blob/…`)를 가리켜서 이 저장소 안에서 열면 그림이 안 보여요. 같은 그림은 [`../mascot/`](../mascot/README.md)에 있어요(`harmonized/…@2x.png` = 화면에 쓴 파일, `cutouts/` = 가공 전 원본 컷아웃). 정확한 화면은 [`../exports/`](../exports/)의 PNG로 확인하세요.
- **움직임**: 보드 안의 일부 요소는 CSS 애니메이션으로 움직여요(S04 떠다니는 편지, 공간 생성·로그인 처리의 오브젝트 순환 로더, S07·S24의 돌아다니는 마스코트). 동작 줄이기 설정에서는 멈춘 채로 보여요. `exports/`의 PNG는 정지 프레임이에요. 규칙은 `interaction-notes.md` §10~§12.
