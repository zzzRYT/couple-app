# assets-spec.md — 에셋 사양서 (방향 A · 손그림)

> **이 폴더의 그림은 디자인 자리표시용 스케치예요.** 실제 앱에 들어가는 최종 에셋은 일러스트레이터에게 의뢰해서 만들고, 그 전까지 이 문서와 `assets-sketch/*.svg`가 크기·선·색·여백의 기준이에요. 스케치의 손 떨림은 좌표에 구워 넣어 흉내 낸 것이고, 최종 그림은 사람이 그린 선이어야 해요. 스케치는 기존 캐릭터·브랜드·작가의 작품을 보고 그리지 않았지만, **닮음 검수는 최종 그림에서** 해야 해요.

## 1. 구성과 개수

| 종류 | asset 수 | 파일 수 | 비고 |
|---|---:|---:|---|
| 마스코트 포즈(서기·인사·앉기·잠자기) | 4 | 16 | 승인 색 4종(기본·숲·노을·바다)을 파일에 구워서 4 × 4 |
| 착용 아이템(머리 2·얼굴 2·목 2·손 2) | 8 | 8 | 슬롯당 하나만 착용 |
| 일반 오브젝트(식물 2·방 소품 4·수집품 3·하늘 3·축하 3·도형 3) | 18 | 19 | 조명만 낮·밤 2개(밤에 불 켜짐 + 납작한 빛 원) |
| **합계** | **30** | **43** | 카탈로그 24~36 범위 안. 방 배경·창문(테마 에셋)은 세지 않아요 |

- 런타임은 **고정 PNG(또는 정적 WebP)** 만 읽어요. 색은 파일에 구워져 있고 앱이 칠하지 않아요(런타임 필터·틴트 없음). 그림자가 구워져 있지 않아서 회전·크기 조절에 안전해요.
- 벡터·레이어 원본(SVG/AI/PSD)은 작업 원본·권리 보관용이고 런타임 번들에 넣지 않아요.

## 2. 파일 사양

| 항목 | 값 |
|---|---|
| 기본 캔버스(pt) | 마스코트 **192 × 192**, 착용품 **96 × 96**, 일반 오브젝트 **128 × 128** |
| 내보내기 | @2x(384 / 192 / 256 px), @3x(576 / 288 / 384 px). 파일명 `{asset id}[__{변형}]@2x.png` |
| 변형 이름 | `__cw-forest`·`__cw-sunset`·`__cw-ocean`(기본 색은 접미사 없음), 조명 밤은 `__night` |
| 배경 | 투명(알파) |
| 포맷 | PNG-8(색이 적어 충분, 알파 포함) 또는 정적 WebP 무손실. sRGB, 알파 미리 곱하기 없음 |
| 용량 목표 | @2x 24KB 이하(마스코트 32KB 이하), @3x는 두 배까지 |
| 회전 안전 영역 | 내용은 캔버스 중심 **지름 90% 원** 안. 앱은 비트맵을 중심 기준으로 회전하고 충돌·보호 영역 계산은 이 원을 써요 |
| 바닥 접촉점 | 바닥에 서는 물건(마스코트·화분·조명 등)은 캔버스 아래 6% 위에 바닥이 닿도록 그려요 |
| 대체 텍스트 | 마스코트와 착용품은 필수(`asset.alt.*`, 3개 언어). 일반 오브젝트는 **장식**이라 읽기 순서에서 빼고 이름(`asset.*`)은 편집 목록에만 써요 |

## 4. 방향 A 스타일 가이드 — 의뢰받은 일러스트레이터를 위한 요약

| 항목 | 규칙 |
|---|---|
| **윤곽선** | 짙은 갈색 #4A3426 한 가지. 두께는 캔버스 한 변의 3.75%(64칸 기준 2.4칸, 192pt 마스코트는 7.2pt). 끝과 이음은 모두 둥글게. 모든 에셋이 같은 두께. |
| **크림 림(스티커 가장자리)** | 윤곽선 바깥으로 #FFF4DF를 캔버스의 2.7%(64칸 기준 1.7칸) 두께로 한 겹. 밤 방(어두운 갈색 벽)에서 모양이 읽히게 하는 장치이고, 낮 방(크림 벽)에서는 거의 안 보여요. 내부에 겹친 선에는 두르지 않아요. |
| **채움색 어긋남** | 파스텔 면을 윤곽선보다 오른쪽 아래로 캔버스의 2.0%, 1.6%(64칸 기준 1.3, 1.0칸) 밀어요. 손으로 찍은 인쇄가 살짝 어긋난 느낌이고, 밀어도 크림 림은 그대로 윤곽선 기준이에요. |
| **손 떨림** | 모든 곡선과 직선에 캔버스의 1.2% 이하(64칸 기준 0.8칸 이하)의 완만한 흔들림. 같은 에셋 안에서는 같은 흔들림을 써서 맞닿는 선이 어긋나지 않게 해요. 런타임 필터로 흉내 내지 않고 그림 자체에 구워요. |
| **채움색 수** | 에셋 하나에 파스텔 채움 4가지 이하(윤곽선·림 제외). 위 팔레트 안에서만 고르고 새 색은 디자인 승인 뒤에 추가해요. |
| **내부 선** | 주름·줄무늬·바늘땀은 윤곽선 색, 두께는 윤곽선의 60~75%. |
| **금지** | 그림자, 광택, 그라데이션, 질감, 반투명, 번쩍임 효과. 하이라이트는 크림색 작은 면 하나까지. |
| **대비** | 윤곽선과 채움색의 대비 3:1 이상(짙은 갈색 렌즈 같은 의도된 어두운 면만 예외), 윤곽선 또는 림 중 하나가 낮 벽·낮 바닥·밤 벽·밤 바닥 모두에서 3:1 이상(측정값은 대비 보고서). |
| **안전 영역** | 내용은 캔버스 중심 지름 90% 원 안. 회전해도 같은 영역이에요. |

### 4.2 마스코트 비율과 착용품 겹침

| 항목 | 규칙 |
|---|---|
| **실루엣** | 목이 없는 콩 모양 몸통. 너비는 캔버스의 약 65%, 높이는 약 69%. 귀·수염·꼬리·부리·큰 눈 같은 동물 특징을 넣지 않아요(기존 캐릭터와 닮음 방지). |
| **반쪽 두 개** | 좌우 두 가지 파스텔 천을 이은 모습: 이음선은 몸통 중앙의 완만한 S자, 바늘땀은 이음선 위 8개(길이 약 6%, 기울기 ±22°, 간격 균등). |
| **얼굴** | 점 눈(지름 약 4%)이 몸통 너비의 38% 간격, 높이는 몸통 위에서 47%. 볼터치는 눈 아래 11%에 장미색 납작한 타원(윤곽선 없음). 입은 짧은 곡선 하나. |
| **팔과 발** | 팔은 몸통 옆 둥근 혹(지름 약 7%), 인사 포즈는 한쪽 팔이 위로. 발은 몸통 아래로 5% 튀어나온 둥근 조각 두 개(몸통 좌우 색). |
| **포즈 4종** | 서기(눈 뜸), 인사(웃는 눈·열린 입), 앉기(반쯤 감은 눈·몸통이 낮고 넓음), 잠자기(감은 눈·몸통 약간 기움·z 글자). 표정은 포즈에 묶여 있어요. |
| **색 4종** | 왼쪽/오른쪽 반쪽 색: 기본(복숭아/하늘), 숲(세이지/버터), 노을(분홍/연보라), 바다(아쿠아/진한 하늘). 볼터치는 장미색 고정. |
| **착용품 겹침** | 착용품은 마스코트 위에 그려지고 자신의 윤곽선과 림을 가져요(몸통 위에서 크림 선이 보이는 것이 의도). 착용 배율 0.85~0.95를 곱해도 선 두께가 마스코트와 같아 보이게 원본 선을 2.5~2.8칸(64칸 기준)으로 그려요. 머리 = 정수리 윤곽을 6% 덮음, 얼굴 = 눈이 보이게(투명 렌즈) 또는 가려지게(선글라스) 눈 위에, 목 = 이음선 아래 몸통 윗부분을 두름, 손 = 오른팔 혹 위에 쥐는 모양. |
| **이름·얼굴 사용** | 이름은 [캐릭터 이름] 자리표시. 앱 이름과 로고도 자리표시예요. |

### 4.3 층 구조(레이어 원본 규칙)
원본은 레이어 3개로 나눠 주세요: **① 림**(크림, 윤곽선 바깥 두께) → **② 채움**(파스텔, 윤곽선보다 오른쪽 아래로 어긋남) → **③ 윤곽선**(갈색 + 내부 선). 이 순서로 합치면 스케치와 같은 모습이에요(`assets-sketch/`의 SVG가 같은 구조). 색 4종 마스코트는 ②의 색만 바꿔서 만들어요.

### 4.4 하지 말 것
그림자·광택·그라데이션·질감·반투명·번쩍임, 새 색 추가(승인 전), 윤곽선 색 변경, 파일마다 다른 선 두께, 기존 캐릭터·브랜드·로고를 참고한 모양, 외부 이미지를 조각으로 쓰기, 생성 이미지.

## 5. 낮·밤 정책과 대비

- 방의 낮/밤은 **두 사람이 같이 보는 방 설정**이라 에셋은 한 벌로 **두 방 모두에서** 읽혀야 해요. 갈색 윤곽선이 어두운 방에서 묻히는 문제는 바깥 **크림 림**이 해결해요.
- 낮·밤 파일이 따로 있는 건 **조명 하나**(`obj_decor_lamp` / `obj_decor_lamp__night`).
- 측정 결과(자세한 표는 `contrast-report.md`):

| 방 면 | 갈색 윤곽선 | 크림 림 | 더 뚜렷한 쪽 |
|---|---:|---:|---:|
| 낮 벽 | 10.38 | 1.02 | **10.38** |
| 낮 바닥 | 8.99 | 1.18 | **8.99** |
| 밤 벽 | 1.33 | 14.12 | **14.12** |
| 밤 바닥 | 1.20 | 12.76 | **12.76** |

- 윤곽선과 채움색의 대비는 3:1 이상(선글라스 렌즈 `#7A5C48` 1.91:1만 의도된 예외).

## 8. 권리·출처·교체 절차

- 매니페스트(`assets-manifest.csv`)의 한 행이 **파일 하나**예요. 열: asset_id, file, variant, kind, slot, category, 이름·대체 텍스트 3개 언어, decorative, canvas_pt, px_2x/3x, format, alpha, color_profile, file_size_target_kb_2x, **sketch_svg_sha256**(이 저장소 스케치의 실제 체크섬), **file_sha256**(최종 파일, 의뢰 후), author, source_evidence, license, **rights_status**, similarity_review_by/date, approved_by, created_at, replace_policy, deprecated_on.
- 스케치 행의 `rights_status`는 `placeholder-sketch-not-final`이에요. 최종 파일은 제작자·원본 증빙(계약서·원본 파일 해시)·라이선스(앱 안 포함·재배포 권한)·닮음 검수자와 날짜가 채워져야 `approved`가 돼요.
- **닮음 검수**: 최종 마스코트·착용품·오브젝트를 기존 캐릭터·브랜드·로고와 비교해 기록해요(특히 마스코트의 두 색 반쪽 + 바늘땀 + 볼터치 조합).
- **교체·폐기**: 새 asset id를 발급하고 이전 id의 `deprecated_on`을 적어요. 기존 방의 버전 스냅샷은 옛 id를 가리키므로 옛 파일은 번들에서 지우지 않고 "삭제된 에셋" 안내(`sys.asset.*`)만 쓰는 시점까지 유지해요.
- 프롬프트가 기존 캐릭터·브랜드를 요청하면 거절하고 "비슷한 분위기의 소품으로 만들어 볼까요?"를 제안해요(`prompt.brand.*`).
