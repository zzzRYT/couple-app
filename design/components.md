# components.md — 컴포넌트 목록 (방향 A · 손그림 따뜻함)

모든 컴포넌트의 **역할 · 변형 · 상태 · 접근성 이름**이에요. 시각 값(색, 간격, 모서리, 글꼴)은 `tokens.json`, 화면에서의 모습은 캔버스 보드 S22(컴포넌트 시트)와 `screens.md`를 보세요.

## 0. 먼저: 시스템 컴포넌트와 직접 그리는 컴포넌트

| 구분 | 컴포넌트 | 구현 원칙 |
|---|---|---|
| **시스템(네이티브 그대로)** | 하단 **탭 바**(iOS UITabBar · Android Material 3 NavigationBar), OS 키보드, OS 공유 시트, 날짜가 아닌 시스템 알림창 | OS가 소유하는 UI예요. Expo의 네이티브 탭 등 **시스템 구현을 쓰고 직접 그리지 않아요.** 앱이 정하는 것은 **틴트 색, 라벨 문구, 아이콘 이미지, (배지: 이 앱은 안 씀)** 뿐이에요. 막대 높이·배경·블러·테두리·그림자·글꼴 크기·선택 애니메이션·아이콘 크기를 바꾸지 않아요. |
| **직접 그리는(방향 A 스타일)** | 방 도구 막대, 버튼, 입력칸, 칩, 배너, 다이얼로그, 시트, 세그먼트, 토글, 목록 행, 말풍선, D-day 위젯, 장면 문구 받침, 마스코트 UI | 갈색 윤곽선(2px · 고대비 3px) + 평평한 면, 그림자 없음, 모서리 반지름이 ±12% 어긋난 손그림 느낌 |

캔버스의 탭 바 그림은 시스템 모습을 **닮게 그린 참고용**이에요(OS 버전에 따라 실제 모습이 조금 달라요). 앱 색은 틴트(`app.*.primary`)와 비선택 틴트(`app.*.text2`)만 따라가요. iOS 기본 회색 비선택 라벨은 4.5:1에 못 미쳐서(`contrast-report.md`) 비선택 틴트를 반드시 지정해요.

## 1. 내비게이션

### 1.1 탭 바 (시스템)
- 항목 4개: 홈 · 방 · 기록 · 설정 (`tab.home`, `tab.room`, `tab.history`, `tab.settings`). 배지 없음(알림 기능 없음).
- 선택 틴트 `app.primary`(밝게 `#B24A24` · 어둡게 `#F0A67F`), 비선택 틴트 `app.text2`. iOS는 선택 시 채운 아이콘, Android는 활성 표시 알약 + 채운 아이콘(시스템 규칙).
- 접근성: 막대 `a11y.tabbar`, 항목 `a11y.tab` ("{name} 탭, 4개 중 {n}번째, 선택됨"). 시스템이 `tablist/tab` 역할과 선택 상태를 줘요.
- 큰 글자: iOS는 시스템이 크기를 정해요(길게 누르면 큰 글자 보기). Android는 라벨과 막대 높이가 커져요.
- 보호 영역: 탭 바는 시스템 소유 UI라서 방 장식이 가리거나 터치를 가로챌 수 없어요. 방 화면의 보호 영역 계산에 높이(iOS 49 + 아래 안전 영역, Android 약 80 + 제스처 영역, 글자 확대 시 증가)를 측정값으로 넣어요.
- 숨김 규칙: 푸시된 상세·작업 흐름·모달에서는 숨겨요(`interaction-notes.md`).

### 1.2 방 도구 막대 (직접 그림 · 방 화면의 **자기 도구 막대**, 위쪽)
- 항목: **되돌리기**(`room.ctl.undo`), **꾸미기**(주 버튼, `room.ctl.decorate`), **기록**(`room.ctl.history`, 기록 탭으로 가는 바로가기).
- 변형: 보통(3개 한 줄) / 글자 ≥160%(꾸미기 한 줄 + 되돌리기·기록 한 줄, 2단). 라벨 글자는 160%에서 멈춰요(자동 축소가 아니라 확대 상한).
- 상태: 기본 / 비활성(점선 윤곽선 + 보조 글자) / 상대 점유 중 — 꾸미기가 **지켜보기**(`room.watch`, 보조 스타일, 눈 아이콘)로 바뀌고 되돌리기는 비활성.
- 윤곽선 색은 **방의 낮밤**을 따라가요(낮 `#4A3426` · 밤 `#E8D3BC` · 고대비 `#1F140D` / `#FFF0DC`, 3px). 앱 모드와 무관하게 경계가 3:1 이상.
- 접근성: 컨테이너 `a11y.toolbar`(툴바), 버튼 이름 `a11y.undo` / `a11y.decorate` / `a11y.history`. 최소 터치 48 × 48(높이 52).
- 레이어: 장면 캔버스 **밖** 네이티브 뷰. 꾸밈 프롬프트가 위치·이름·동작을 바꿀 수 없어요.

## 2. 입력과 버튼

### 2.1 버튼
| 변형 | 용도 | 면 / 글자 / 윤곽선 |
|---|---|---|
| primary | 한 화면의 주된 행동 | `primary` / `onPrimary` / `line` |
| secondary | 보조 행동 | `surface` / `text` / `line` |
| danger | 되돌릴 수 없는 확정(공간 종료·차단) | `danger` / `onDanger` / `line` |
| dangerOutline | 위험하지만 덜 강조(동의 철회, 차단 진입) | `surface` / `danger` / `danger` |
| ghost | 텍스트 버튼(다시 시도, 나중에, 새 코드 만들기) | 투명 / `primary` |

상태: 기본 · 눌림(밝기 −10%, 1px 아래) · 포커스(3px 링 + 3px 간격) · 비활성(점선 윤곽선, `surface2` 면, `text2` 글자) · 로딩(스피너 + 라벨 유지). 높이 52(최소 48), 알약. 글자는 **굵은 글씨 글꼴**(16px, 손글씨 아님). 접근성: 라벨이 이름, 로딩 중 `a11y.progress`("진행 중")를 상태로.

### 2.2 아이콘 버튼
지름 48, 면 `surface`, 윤곽선 `line`. 아이콘만 있으면 반드시 접근성 이름(`a11y.back`, `a11y.close`, `a11y.send` …).

### 2.3 텍스트 입력
- 단일 줄: 라벨(굵은 글씨 14) 위 + 칸 + 도움말/오류 아래. 상태: 기본 / 포커스(`focus` 윤곽선 + 링) / 오류(`danger` + 아이콘 + 문구) / 읽기 전용·비활성(`surface2`).
- **프롬프트 입력**(멀티라인 2줄 시작, 보내기 원 버튼 52): 상태 — 입력 가능 / 제출 중(잠김 + 스피너) / **상대 점유로 잠김**(잠금 아이콘 + 이유 문구 `prompt.input.partner`) / 동의 필요·한도 소진·오프라인(각각 이유 문구). 이름 `a11y.input`, 잠겼을 때 `a11y.input.ro`.
- **초대 코드 8칸**(4+4, 200%에서 두 줄), **인증 코드 6칸**: 한 칸씩 읽지 않고 전체를 `a11y.code`로 읽어 주며 붙여넣기를 지원해요. 오류 시 `danger` 윤곽선 + 문구(색만으로 구분하지 않음).
- **날짜 3열 휠**: 달력이 아니에요. 순서는 ko/ja 년·월·일, en 월·일·년. 접근성 이름 `a11y.dateField`, 증감 동작(스와이프/위아래)을 제공.

## 3. 상태 표시

### 3.1 칩
neutral / info / success / warn / danger / primary. 아이콘 + 글자 + 윤곽선(색만으로 구분하지 않음). 글자는 굵은 글씨 13.

### 3.2 점유 표시 칩 (프롬프트 세션)
| 상태 | 문구 | 모양 |
|---|---|---|
| free | `prompt.free` | 보조 윤곽선, 일시정지 아이콘 |
| mine | `prompt.mine` (+ 카운트다운 `0:30`) | primary 면, 연필 아이콘 |
| partner | `prompt.partner` | warn 면, 잠금 아이콘 |
| released | `prompt.free` | free와 같음 |

접근성: `a11y.presence`, 만료 임박 시 `a11y.countdown`을 한 번만 알려요(매초 읽지 않음).

### 3.3 배너 (info · success · warn · danger · offline)
면 `*Bg` + 같은 계열 윤곽선 + 아이콘 + 제목(굵게) + 본문 + 선택적 텍스트 행동(물결 밑줄). `role=status`로 조용히 알려요(오류 화면 전환은 `alert`).

### 3.4 토스트
어두운 갈색(밝게)/크림(어둡게) 면, 성공 체크 아이콘, 3초 후 사라짐(동작 줄이기면 즉시). 중요한 정보는 토스트에만 두지 않고 화면 상태로도 남겨요.

### 3.5 스켈레톤 · 로딩 · 빈 · 오류
- 스켈레톤: `surface2` 면 + 텍스트 `common.loading`/`*.loading`. 고대비에서는 점선 윤곽선.
- 빈 상태: 마스코트(앉기) + 제목(손글씨) + 설명 + (있으면) 행동 버튼.
- 오류: "무엇이 그대로인지"를 먼저 말해요. 배너 또는 전체 화면(S16).

## 4. 겹침 UI

### 4.1 다이얼로그
면 `surface`, 윤곽선 `line` 2px, 모서리 손그림 반지름, 아이콘 원 + 제목(손글씨 20) + 본문 + 세로로 쌓은 버튼. 파괴적 행동은 danger. `role=dialog aria-modal`, 열리면 제목으로 초점 이동, 닫으면 호출한 버튼으로 복귀.

### 4.2 바텀 시트
상단 모서리 둥글게, 손잡이 막대, 제목 + 내용. 키보드가 있으면 키보드 위로 올라가요. 배경 스크림 `rgba(43,35,32,.5)`. **탭 바를 덮어요.**

### 4.3 첫 실행 안내(코치 마크)
짙은 갈색(밝게)/크림(어둡게) 말풍선 + 꼬리 + "알겠어요". 한 번 닫으면 다시 안 나와요. `role=status`, 이름 `a11y.coach`.

## 5. 선택 컨트롤
- **세그먼트**: 안쪽 면 `surface2` + 윤곽선, 선택된 항목은 `primary` 면 + 굵은 글씨. 아이콘 + 라벨(색만으로 구분하지 않음). 사용처: 방 낮·밤(시간대 따라/낮/밤), 화면 모드(기기 설정/밝게/어둡게), 미리 보기(현재 방/미리 보기).
- **토글**: 켬 = primary 면, 끔 = `surface2`, 둘 다 윤곽선 + 둥근 손잡이. 이름 `a11y.switch`("{name}, 켜짐/꺼짐").
- **체크박스 · 라디오**: 26px, 윤곽선 `line`, 선택은 primary 채움/체크.

## 6. 목록과 카드
- **목록 행**: 아이콘 + 제목 + 값 + 화살표, 높이 ≥56. 위험 행(공간 종료)은 `danger` 글자 + 설명.
- **설정 그룹 카드**: 윤곽선 `divider`(고대비 `line`) 안에 행들을 구분선으로.
- **버전 카드**: 섬네일(방의 현재 낮/밤 모습, 손그림 모서리) + "버전 N" + 지금 방 칩 + 변경자·시각 + 변경 요약 태그. 접근성 `a11y.version`. 프롬프트 전문은 목록에 안 보여요.

## 7. 프롬프트 패널
- 구성: 방 축소 보기(전체 방을 약 0.6배로, 도구 막대·탭 바 없이) → 패널(제목 + 닫기, 점유 칩, 탭[프롬프트·마스코트(후속 설계)], 대화, 입력).
- **말풍선**: 내 말(primary 면, 오른쪽), 상대 말(`surface2`, 이름 + 시각), 시스템 상태 칩(미리 보기 만듦·적용함·취소함·풀림), 결과 카드(윤곽선 `line`, "제안"), 타이핑 표시(점 3개), 작업 중(스피너).
- **미리 보기 배지**: 방 축소 보기 아래 가운데 알약 "미리 보기 · 아직 적용되지 않았어요"(방이 안 바뀐다는 점을 항상 표시).
- **현재 방/미리 보기 전환**(세그먼트) · **적용 / 취소 바**(점유자만 활성, 상대는 비활성 + "{name}님이 적용할지 정하고 있어요").
- **키보드**: OS 키보드는 패널을 위로 밀고, 방 축소 보기는 얇은 띠로 줄어요. 도구 막대·탭 바는 모달이 덮고 있어서 가릴 일이 없어요.

## 8. D-day 위젯 (네이티브 · 앱 소유 의미 위젯)
- 장면 캔버스에서 그리지 않고 별도 네이티브 뷰로 겹쳐요. 하트 아이콘 + 눈썹 글자(`dday.eyebrow`) + 일수(`dday.count`, 손글씨 24).
- **프롬프트로 바꿀 수 있는 것**: 위치(보호 영역 밖), 모양(알약/둥근 사각 등 승인 목록), 색(**프리셋 6종**: 버터·복숭아·세이지·하늘·분홍·크림, 모두 갈색 글자 6.8:1 이상), 크기(글자 확대 배율 위로 최소 크기 보장), 방에서 숨기기.
- **바꿀 수 없는 것**: 날짜 값, 계산, 접근성 문장(`a11y.dday`), 메인 홈의 D-day.
- 윤곽선 `#4A3426` + 크림 림은 고정(낮밤 방 모두에서 경계 확보). 접근성: 하나의 `text` 요소로 "함께한 지 483일째, 2025년 6월 29일부터"(언어별 템플릿).
- 숨겨져 있으면 방에 안내 배너(`room.ddayHidden`)를 보여요.

## 9. 장면 구성요소
- **에셋 오브젝트**: 고정 이미지(`assets-spec.md`). 장식은 기본적으로 접근성 읽기 순서에서 제외(`a11y.decor`). 회전·크기·레이어 순서는 장면 데이터가 정해요.
- **마스코트**: 기본 방에 1개(소유자 제공 캐릭터를 방향 A로 다듬은 고정 PNG, `design/mascot/harmonized/`). 대체 텍스트 `a11y.mascot` + 포즈명(`a11y.pose.*`). 최소 높이 48px, 여백 = 높이의 10%, 위에 글자·컨트롤을 얹지 않음. 방 안 포즈 6종(소품 없음)만 장면 오브젝트로 쓰고 소품 포즈와 뒷모습은 화면 일러스트로만 써요.
- **장면 문구 받침**: 크림 종이(`#FFF8EC`) + 갈색 글자 + 갈색 윤곽선 + 크림 림, 자동으로 깔려요(글자 12.5:1 이상). 글자 크기 최소 20pt, 손글씨 글꼴(없는 글자가 있으면 문장 전체를 본문 글꼴로). 방 문구는 입력한 그대로 읽어요.
- **방 배경(테마 에셋)**: 크림 벽(`#FBF1E3`)/어두운 갈색 벽(`#2B2320`), 바닥색, **손으로 그린 한 줄 바닥선**(화면 높이 68%), 나무 아치 창(낮: 해와 구름, 밤: 달과 별).

## 10. 마스코트 꾸미기 UI — 대체됨
착용 슬롯 UI(슬롯 카드 4 · 아이템 행 · 승인 색 원 · 포즈 카드)는 마스코트 변형을 프롬프트로 생성하는 방식으로 **대체돼서 더 만들지 않았어요**. 새 화면(프롬프트 입력 + 허용 변경 칩, 생성 중, 후보 2~3개 고르기, "그건 바꿀 수 없어요" 거절, 한도 소진, 이전 버전·복원, 기본 마스코트로 되돌리기)은 조사 후 후속 설계예요(`handoff.md` §11). 마스코트 이미지 컴포넌트는 캔버스 S22에 있어요.

## 11. 서드파티·OS 컴포넌트
- **카카오·Apple 로그인 버튼**: 공식 에셋/규정 그대로(카카오 노랑 `#FEE500` + `#191919`, Apple 흑백). 캔버스의 모양은 자리표시.
- **OS 공유 시트 · OS 키보드**: 시스템 UI. 앱은 공유 문구(`invite.shareMsg`)만 넘겨요.

## 12. 상태별 접근성 요약
- 색만으로 구분하는 곳 없음: 오류/성공/경고는 색 + 아이콘 + 문구, 선택은 윤곽선 두께·채움·체크.
- 포커스 순서는 화면의 시각 순서(위 → 아래, 왼쪽 → 오른쪽). 고정 영역(탭 바)은 마지막.
- 모든 상태 변화(점유 변경, 미리 보기 생성, 적용, 오류)는 `role=status`로 한 번 알리고, 연속 입력 중에는 방해하지 않아요.
- 동작 줄이기: 스켈레톤·스피너 이외의 전환 애니메이션을 끄고, 스피너는 정지된 호 모양으로 대체.
