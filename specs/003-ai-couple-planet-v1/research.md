# V1-S1 rendering

Expo GL with React Three Fiber and three.js follows the P01 candidate and the K02 loader example. It supports the native scene and GLB swap in the Expo development build. A pre-rendered turntable cannot support free camera movement or future surface objects; a separate game engine would add a second runtime. Device performance remains to be measured before accepting the stack.

The owner has not supplied `aroomi-v1-tpose.glb`. `Aroomi` is a temporary primitive model, and T104 stays open. The real model and its mobile optimization must replace it later.

On the iOS 26.5 simulator, the original scene stayed blank even though the GL context and callbacks ran. A raw GL clear displayed correctly. The actual planet scene reported OpenGL ES 3.0, 13 draw calls and a linked program with compiled shaders. Direct framebuffer `readPixels` returned `INVALID_OPERATION`; the iOS view uses a multisampled buffer, so that read does not establish whether drawing failed. Submitting queued GL work with `flushEXP` before each `endFrameEXP` displayed the planet and allowed the Aroomi animation to advance. This is a simulator workaround, not a confirmed explanation of the original memory incident. The scene unmounts on blur or background and uses demand rendering for reduced motion. Physical-device frame rate, first-show time and gesture behavior remain to be measured. Three.js 0.187's CommonJS entry calls `process.emitWarning`, unavailable on Hermes; the local compatibility shim runs before the scene import.

`SurfaceAnchor` places a child using latitude and longitude on the same procedural surface as the planet. The scene has an object group for future placements. `loadPlanetAsset` parses GLB bytes into an owned scene; the caller supplies the bytes, attaches the scene under an anchor and calls `disposePlanetAsset` when it is no longer used. Asset download, shared ownership and generated-object UI belong to later slices. Parsing an empty GLB was checked locally; a textured owner or generated GLB has not yet been tested on a device.
